# Telegram-бот для OSNOVA: подключение

## Что умеет
- Присылает каждый новый репорт с кнопками **✅ Принять / ❌ Отклонить / 🔗 Админка / 🚗 На сайте**.
  Нажатие меняет статус в базе, пишется в журнал (кнопка «Откатить» в админке работает),
  сообщение обновляется: «✅ Принято — Telegram: @имя», а кнопка меняется на «↩️ Вернуть в новые».
- Команды: `/menu` (меню с кнопками), `/find` (поиск машины, в личном чате можно просто писать название), `/car` (карточка с цветами и фото), `/top` (популярное), `/recent` (новые машины), `/health` (здоровье каталога), `/audit` (правки админов), `/new` (5 свежих репортов с кнопками), `/stats` (сводка), `/help`.
  что без обложки и скриншота), `/help`.
- Утренняя сводка раз в сутки (07:00 UTC), только если есть неразобранные репорты.
- По желанию: лента правок админов (кто, что и где изменил), без звука.
- Поддержка темы форума-группы (TELEGRAM_THREAD_ID).

## Подключение (один раз)
1. В Telegram создай бота у @BotFather, возьми токен.
2. Напиши боту любое сообщение (для группы — добавь бота в группу).
3. Узнай свой id у @userinfobot и id чата (для личного чата он равен твоему id).
4. Сгенерируй секреты:
   `node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"` — два раза
   (для TELEGRAM_WEBHOOK_SECRET и CRON_SECRET).
5. В Vercel → Environment Variables задай:
   - TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID
   - TELEGRAM_WEBHOOK_SECRET
   - TELEGRAM_ADMIN_IDS — id людей, которым можно нажимать кнопки (через запятую).
     Если чат — группа, это ОБЯЗАТЕЛЬНО: без списка бот отказывает в группах.
   - CRON_SECRET
   - необязательно: TELEGRAM_THREAD_ID, TELEGRAM_AUDIT_FEED=1
6. Задеплой, затем из корня проекта (в .env должны быть TELEGRAM_BOT_TOKEN и TELEGRAM_WEBHOOK_SECRET):
   `node scripts/telegram-setup.mjs https://твой-сайт.vercel.app`
   Проверить состояние: `node scripts/telegram-setup.mjs --info`; отключить: `--delete`.

## Безопасность
- Запросы от Telegram принимаются только с секретом вебхука (заголовок, сравнение за постоянное время).
- Кнопки и команды работают только из твоего чата и (если задан) для id из TELEGRAM_ADMIN_IDS.
- Сообщения репортов экранируются, посетитель не может вставить в них разметку.
- Токен бота никогда не попадает в браузер: переменные без префикса VITE_.

## Ограничения
- Если статус сменили на сайте, старое сообщение в Telegram не обновится. Источник правды — база.
- Бот пока не отвечает автору репорта (контакт — свободный текст: VK, Discord и т.п.).
